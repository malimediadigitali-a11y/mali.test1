# Adeshborde Interactivy

This project is a simple interactive desktop application built with Python and Tkinter. It collects a user's name and age and then displays a personalized greeting message.

## Features

- User-friendly GUI with input fields for **name** and **age**
- "Submit" button to create a custom greeting
- Responsive label showing the output message

## Getting Started

### Prerequisites

- Python 3.x

Tkinter comes included with most Python installations. If you encounter issues, you can install it using:

```bash
pip install tk
```

### Running the Application

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the app with:

```bash
python maine.py
```

### Usage

1. Enter your name in the first field.
2. Enter your age in the second field.
3. Click the "Submit" button.
4. See your personalized greeting displayed below.

## Example

```
Enter your name:  Alice
Enter your age:   30
[Submit]
Hello, Alice! You are 30 years old.
```

## File Structure

- `maine.py` - Main Python file containing the Tkinter application.
